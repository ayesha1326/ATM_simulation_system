# ATM Simulation System 

This project simulates real-world ATM operations with a modern UI, transaction handling, and receipt generation.

---

## 🚀 Project Overview

The ATM Simulation System is designed to replicate basic banking operations such as login authentication, balance inquiry, deposits, withdrawals, transaction history tracking, and receipt generation.

It includes a **professional user interface with background images and blur effects**, making it visually appealing and user-friendly.

---

## 🎯 Features

### 🔐 Authentication System
- Secure login page
- User validation before accessing dashboard

### 💰 Account Dashboard
- Displays user details
- Shows real-time account balance

### ➕ Deposit Money
- Add funds to account
- Instant balance update
- Transaction recorded automatically

### ➖ Withdraw Money
- Withdraw funds securely
- Prevents overdraft (insufficient balance check)

### 📜 Transaction History
- Stores all transactions (Deposit / Withdraw)
- Includes timestamp for each action

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript  
- **Backend Logic:** Python  
- **Data Storage:** JSON
